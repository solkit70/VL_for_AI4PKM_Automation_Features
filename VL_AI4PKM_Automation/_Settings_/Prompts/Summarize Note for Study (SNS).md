# Summarize Note for Study (SNS)

긴 학습 노트를 핵심 개념 중심으로 요약하여 빠른 복습이 가능하도록 합니다.

## Input
- Source: vl_ai4pkm_materials/*.md 또는 Topics/Learning/*.md
- 학습 노트 마크다운 파일 (강의 노트, 튜토리얼, 기술 문서 등)

## Output
- File: AI/Study/{{filename}}_summary.md
- 핵심 개념 중심의 간결한 요약 문서

## Main Process
```
1. 노트 분석
   - 전체 노트를 읽고 주요 주제 파악
   - 핵심 개념과 부차적 내용 구분
   - 학습 목표 및 중요도 평가

2. 핵심 개념 추출
   - 가장 중요한 개념 3-5개 선정
   - 중복되는 내용 통합
   - 명확하고 간결하게 표현

3. 요약 작성
   - 전체 흐름을 유지하면서 압축
   - 구체적인 예시는 간략화
   - 이해를 돕는 핵심 예시만 포함

4. 실습 정리
   - 실제로 해볼 수 있는 항목 추출
   - 순서대로 정리
   - 체크리스트 형태로 제공

5. 연결 제안
   - 관련 있는 다른 학습 주제 찾기
   - 다음 학습 방향 제시
```

> 원본: [[{{filename}}]]

## Important Notes

1. **간결성 우선**: 원본의 30-40% 길이로 압축
2. **핵심 집중**: 가장 중요한 개념에 집중
3. **실용성**: 복습 시 실제로 도움이 되는 내용 포함
4. **연결성**: 다른 학습 자료와의 연결 제시
5. **체크리스트**: 이해도를 확인할 수 있는 항목 제공
